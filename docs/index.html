O que faz

Funcionalidades que correm 100% local na tua máquina, contra um único ficheiro SQLite.

⊞

Multi-conta

Várias contas bancárias, cartões e carteiras e-money lado a lado. Saldos calculados em tempo real.

↑

Import .xlsx / .csv

Detecta colunas em formatos PT (Data Operação, Montante, Saldo). Locale-aware: lê 1.234,56 € sem chiar.

✦

Auto-categorização

Regras por palavra-chave (contains / exact / startswith / regex). Importações futuras categorizam-se sozinhas.

€

Tracking de créditos

Modela cada empréstimo (total, prestação, prazo). Pagamentos ligam-se automaticamente via regras.

↔

Deteção de pares

Encontra transações que se anulam (pagamento + reembolso) com tolerância configurável de valor e janela de dias.

↶

Undo de 5s

Apagar é reversível: toast com botão Anular antes de qualquer DELETE chegar à base de dados.

Como instalar

Windows com Python 3.11+ e Node.js 18+ instalados.

1

Clonar

git clone https://github.com/celiaagoncalves/euroly.git
cd euroly
2

Arrancar

start.bat

Primeira execução cria venv + npm install. Seguintes são instantâneas.

3

Abrir

http://localhost:5173

O browser abre sozinho. Configura contas em Backoffice e importa o teu extrato.

Privacidade. A base de dados (backend/euroly.db) fica só no teu computador. Nenhum dado é enviado para servidores externos. Não há contas, não há telemetria, não há tracking. Os nomes das tuas instituições e credores nunca aparecem no código do repositório.
